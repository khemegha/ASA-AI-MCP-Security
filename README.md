## MCP connects your AI to everything. That is the risk — and the opportunity.

The **Model Context Protocol (MCP)** links AI agents to tools and data. It supercharges automation — and opens a new attack surface: over-privileged tools, prompt injection through tool outputs, untrusted MCP servers.

**ASA-AI MCP Security** turns that same protocol into an advantage: an **AI agent that runs offensive security**, and a layer that **secures the AI itself**.
